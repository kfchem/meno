# ワークフロー

たくさんの分子に一度に計算をする方法です。分子のセットをステップにつなぎ、それぞれのステップの結果を次のステップへつないで、何かが変わればまとめてもう一度走らせます。

## 出発点のセット {#sets}

構造か、3D の分子を選びます。選んだものの右端に、小さな輪のポートが出ます。そこからワイヤーを引き出すと、選んだものが細い枠のセットになり、ワイヤーがポインターについてきます。選んだものを右クリックして「Use as input」を選んでも同じです。

- 何もないところで離すと、そこに、そのセットの中身を受け取れるステップが並びます。
- ステップの入力の上で離すと、セットがそこにつながります。
- 受け取れるもののないところで離すか、Escape を押すと、ワイヤーは消え、セットは残ります。

セットには、作ったときに枠の中にあったものが、ページに並んだ順（上から下、左から右）で入ります。自分で作ったセットにものをドラッグして入れたり出したりすると、加わったり外れたりします。

- 構造をつかんでいる間、セットの枠は、離したらどうなるかを示します。構造を取り込むときは縁に色が付き、構造がセットから外れるときは縁が灰色の破線になります。
- 枠は中身に合わせて広がり、中身より小さくはなりません。辺や角をドラッグすると大きくでき、その大きさは保たれます。
- 広がった枠がほかのセットに重なると、そのセットを押しのけます。一回の取り消しで、ドラッグと、それで動いたものがすべて元に戻ります。

## ステップ {#steps}

ステップは、一つの種類の計算です。Meno か、プラグインが行います。何もないところをダブルクリックして「Calculations」を選び、ステップを選びます。一行ごとに、追加したプラグインか Meno と、それが行えるステップの種類が並んでいます。

- ステップのカードには、何をどうするかと、いまの状態が出ます。「Ready」「Waiting」「Running」「Done」「Failed」「Stopped」、または「Changed · run again」です。
- カードをクリックすると、オプションが開きます。ダブルクリック、「Close」、Escape で閉じます。
- ステップは、Settings の「Calculations」にある既定値で始まります。カードで変えたものは、そのステップだけに効きます。
- プラグインのステップの数値や文字のオプションと、「Torsion restraints」の強さは、各エントリーが持つプロパティから取らせることができます。エントリーごとに別の値になります。欄の右端の小さなボタン「From a property」を押し、プロパティの名前を入力します。もう一度押すと、カードの値に戻ります。そのプロパティを持たないエントリーは、理由を添えて「Failed」から出ます。

## ワイヤーとポート {#wires}

ステップはカードの左端で受け取り、右端から渡します。入力ごとにポートが一つ、出口ごとにポートが一つあり、二つ以上あるときは名前が付きます。最初の出口は、ステップが残したもの、作ったものを渡します。後ろの出口（「Failed」や「The rest」など）は、ステップが外したものを渡します。

- 出口のポートからほかのステップの入力へドラッグすると、つながります。ドラッグしている間、受け取れる入力が光ります。
- 運んでいるものを受け取れない入力にはつながらず、カードがその理由を言います。
- 一つの出口から、いくつものステップへつなげます。入力にはワイヤーが一本だけで、新しくつなぐと入れ替わります。
- ワイヤーを消すには、ポインターを載せて Delete を押すか、そのメニューを使います。入力からワイヤーの端を引きはがし、何もないところで離しても消えます。

## ポートからステップを足す {#adding}

ステップの出口からワイヤーを引き出し、何もないところで離すと、そこに、その出口が渡すものを受け取れるステップだけが並びます。選んだステップは、元のカードのすぐ右に置かれます。入力がポートと同じ高さになるので、ワイヤーはまっすぐです。そこにすでに何かがあれば、元のカードの下に置かれます。ステップはつながった状態で置かれ、一回の取り消しで両方とも消えます。

## 結果の行き先 {#results}

ステップが出したものは、その出口に入ります。

- ほかのステップへつながった出口には、枠が出ません。結果はページの外に預けられ、ワイヤーはカードからカードへ走り、次のステップはそこから受け取ります。
- どこにもつながっていない出口は、カードの右の枠に結果を出します。ページのほかのものと同じように、手に取って扱える分子や構造です。ステップが走るまで、枠には「Not run yet」と出ます。
- ステップが外したものの出口（「Failed」「The rest」）は、何も入っていない間はポートだけです。何か入ると、枠が出ます。
- ほかのステップへつながった出口のポートを指すと、その結果が何を持っているかが横に出ます。
- ページの外に預けた結果を見るには、出口のポートをクリックするか、右クリックして「Show on the page」を選びます。ワイヤーなら、右クリックして「Show its results on the page」を選びます。結果は、枠があった場所に並びます。もう一度ポートをクリックすると、またページの外に預けられます。
- 50 を超えるセットは、枠の中に要約を出します。メニューの「Open as a table」で、右の列に表として開きます。

## 走らせる {#running}

ステップを右クリックして「Run」を選ぶと、まだ走っていないもの、変わったもの、失敗したもの、止めたものが前にあれば、それを先に走らせてから、そのステップが走ります。「Run from here」は、そのステップとその後のステップをすべて走らせます。何もないところの右クリックで「Run all」、何かが走っている間は「Stop all」が選べます。

- 走ったあとでオプションか受け取るものが変わったステップは「Changed · run again」と言い、もう一度走るまで前の結果をそのまま持っています。
- 走ったあとのステップのメニューには、「Show log」と「Show files」があります。
- ステップの結果は、取り消し一回分としてまとめて入ります。

## ステップを繰り返す {#repeat}

「Repeat」は、ステップを囲む枠で、中のステップを一回ずつ繰り返し走らせます。ある回で出たものを、終わるまで何度でも回せます。

- 何もないところをダブルクリックして「Calculations」を選び、Meno の行の「Repeat」を選びます。空の枠が置かれるので、そこへステップをドラッグして入れます。
- または、ステップか、選んだいくつかのステップの一つを右クリックして「Repeat these steps」を選びます。それらを囲んで枠が描かれ、枠の縁をまたいでいたワイヤーは、枠を通るようにつなぎ直されます。そのステップに二つ以上のセットが入ってくるときは Repeat は作られず、Meno がその理由を言います。
- どちらも、一回の取り消しで消えます。

カードは枠の左上にあります。

- カードの「In」は、外から来るものを受け取ります。
- 枠の中の「This pass」は、その回のエントリーを、中の最初のステップに渡します。
- もう一回まわすものは「Again」に、終わったものは「Done」につなぎます。
- 枠の外の「Out」には、すべての回で「Done」に届いたものが集まります。

カードの真ん中が枠の中にあるステップが、その Repeat に入ります。カードをドラッグして入れたり出したりすると、加わったり外れたりします。ワイヤーが枠をまたげるのは、これらのポートを通るときだけです。それ以外のまたぎ方をするワイヤーはつながらず、カードがその理由を言います。

カードをクリックすると、オプションが開きます。

- 「Repeat」：「A number of times」、「Until none goes again」（「At most, passes」とともに）、「Over values」のどれかです。
- 「Variable」：名前と、「From」と「Step」、または「Values, one to a line」、そして「Unit」です。各エントリーはその名前で変数を持ちます。これはプロパティなので、中のステップのオプションをそこから取らせることができます（[ステップ](#steps)を参照）。
- 「Counted」：「Per entry」なら、各エントリーの値は、そのエントリーが一回まわるごとに進みます。「Per pass」なら、回ごとに進みます。
- 「Each pass starts」：各回をどこから始めるかです。制約を最初にかけた所（「From where restraints were first held」）、前の回（「From the last pass」）、入ってきたもの（「From what came in」）のどれかです。

ほかのステップと同じように走らせます。走っている間は、いま何回目かを示します（「pass 2 of 3」）。中のステップが失敗すると、そこで繰り返しは終わり、Repeat は、どのステップが何回目で失敗したかを言います。回が尽きたときにまだまわっていたものは「Out」から出て、行にその数が出ます。

## テンプレート：描いた反応からエネルギー図まで {#template}

結果を持たず、ワークフロー全体を収めたワークスペースが二つあります。どのステップも、あなたが変えてよい出発値に設定されています。「confots-xtb.meno」は描いた反応からそのエネルギー図まで、「confots-dft.meno」はエネルギー図の先の DFT の段階まで続きます。どちらも Meno のリポジトリの [templates フォルダー](https://github.com/kfchem/meno/tree/main/templates)にあります。

1. Settings の「Plugins」で、RDKit のプラグインと ORCA のプラグインを追加します。
2. どちらかのファイルを開きます。
3. 「The reaction: draw over it」という枠の中にあなたの反応を描き、例を消します。
4. 何もないところを右クリックして「Run all」を選びます。

段階は一行ずつで、ページ上に見出しがあります。

- **反応。** 反応を囲むセットが、矢印から各構造の役割（反応物、生成物、試薬）を決めます。試薬は除かれます。512 g/mol より重い反応物は断られます。数はそのフィルターで変えられます。
- **化学種ごとの 3D。** 反応物と生成物のそれぞれに、水素をすべて持つ 3D 構造を一つずつ作り、生成物を反応物の番号に合わせます（「Atom map」）。
- **化学種ごとのコンフォマー。** コンフォマー探索を行い、最低から 10 kcal/mol 以内のものを残して最適化し、重複を除き、さらに 5 kcal/mol 以内の最大 64 個にします。
- **ペア。** 片側の各コンフォマーにもう片側の結合を与えて最小化します。二つの向きがどちらもつながっていて、「Pass the side with fewer」が、化学種あたりのコンフォマーが少ない側か、両方を通します。
- **経路。** 各コンフォマーからその終点への経路探索を行い、最高点を鞍点の推測にして、虚振動がちょうど一つのものを残します。そこから反応経路を両向きにたどり、両端が、その鞍点の作られた相手の反応物と生成物であるものを残します。
- **図。** 極小点と鞍点を、自由エネルギーとともに「Energy diagram」に描きます。ゼロは反応物に置き、各障壁は、その鞍点を作った反応物の最安定コンフォマーから測ります。

テンプレートは、反応物の構造が一つであること（または、一つとして描いた反応物）を前提にしています。ステップができなかったエントリーは、その「Failed」の出口から出ます。別のオプションでやり直すには、「Failed」をそのステップのコピーにつなぎ、そこで変えたいところを変えます。端まで届かずに止まった反応経路は、届いた所まで残り、ステップの行にそのことが出ます。

## 保存と共有 {#saving}

ワークスペースには、ワークフローが結果ごと残ります。セット、ステップ、ワイヤー、オプション、そしてそれぞれの実行です。ほかのコンピューターで開いても読め、同じプラグインが追加されていればもう一度走らせられます。

- ステップか、そのセットを右クリックして「Save as procedure…」を選ぶと、データ抜きのステップの並びが残ります。保存した手順は、何もないところをダブルクリックして出てくる「Calculations」にあり、置くとつながった状態で現れ、入力を待ちます。
- ワークフローの部品は、描いたものと同じようにコピー、切り取り、貼り付け、移動、削除ができます。
