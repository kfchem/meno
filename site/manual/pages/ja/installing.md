# インストール

Meno は Windows 10 と 11（64 ビット）と、Apple シリコン（M1 以降）を搭載し macOS 13 以降が入った Mac で動きます。無料で、許可すれば自分で最新の状態を保ちます。

## ダウンロード {#download}

どちらも [Meno のウェブサイト](/#download)からダウンロードできます。ファイルは GitHub にあるプロジェクトの[リリース](https://github.com/kfchem/meno/releases/latest)から取られています。

- Windows：`Meno_<version>_x64-setup.exe`
- Mac：`Meno_<version>_aarch64.dmg`

リリースにあるほかのファイルは、Meno が自分を更新するときに使うものです。ダウンロードする必要はありません。Intel 搭載の Mac 向けと Linux 向けのビルドは、まだありません。

## Windows では {#windows}

1. インストーラーをダウンロードします。Edge が、このファイルは一般的にダウンロードされていない、と表示したら、ダウンロードの横の「…」（その他のアクション）から「保存」（Keep）を選びます。もう一度尋ねられたら「詳細表示」（Show more）、「保持する」（Keep anyway）の順に選びます。
2. インストーラーを開きます。「Windows によって PC が保護されました」と表示されたら、「詳細情報」（More info）を選び、続けて「実行」（Run anyway）を選びます。
3. インストーラーは何も尋ねません。小さなウィンドウが出ている間に、Meno がこのアカウントだけにインストールされます。そのため管理者のパスワードは要りません。終わると Meno が開きます。
4. 次からは、スタートメニューかデスクトップから Meno を開きます。

> Edge と Windows がインストーラーについて警告するのは、インストーラーにまだ、それらが知っている証明書による署名がないためです。

## Mac で初めて開くとき {#mac}

1. ディスクイメージを開き、Meno を「アプリケーション」フォルダにドラッグします。管理者でないアカウントでは、そこに入れるために管理者の名前とパスワードを求められます。
2. 「アプリケーション」から Meno を開きます。初めてのときは、Meno にマルウェアが含まれていないことを検証できなかった、と macOS が表示し、Meno は開きません。「完了」（Done）でメッセージを閉じます。「ゴミ箱に入れる」は選びません。
3. 「システム設定」を開き、「プライバシーとセキュリティ」を選びます。「セキュリティ」の下で、Meno についての行の横にある「このまま開く」（Open Anyway）を選び、求められたらパスワードを入力します。
4. もう一度 Meno を開きます。macOS がもう一度尋ねたら「このまま開く」を選びます。これは記憶されるので、一度だけで済みます。

> macOS が尋ねるのは、Meno がまだ Apple の公証を受けていないためです。Meno はディスクイメージからではなく「アプリケーション」から開いてください。ディスクイメージから開いた Meno は、自分を更新できません。

## 最初の質問 {#first-question}

Meno で初めて何かをしたとき（構造を置く、ファイルを開く、Settings を開くなど）、Meno は「Keep Meno up to date?」と尋ねます。「Allow and download」を選ぶと、起動したときと数時間ごとに GitHub で新しいバージョンを探し、バックグラウンドでダウンロードして、終了するときにインストールします。「Not now」を選ぶと、どれもしません。あとからいつでも、Settings の「Network」にある「Keep Meno up to date」で変えられます。

## 更新 {#updates}

Meno が自分を最新に保っている間は、新しいバージョンがバックグラウンドで届き、終了するときに入ります。お知らせの「Restart now」を選ぶと、すぐに入ります。Windows では、計算ジョブが待機中か実行中の間は待ちます。インストールするとジョブが止まってしまうためで、ジョブのない状態で終了したときに入ります。

Mac で、Meno が自分のアカウントでは変更できないフォルダ（管理者でないアカウントにとっての「アプリケーション」など）にある場合は、更新を入れて終了するときに、macOS が管理者の名前とパスワードを求めます。キャンセルすると、Meno は元のままです。

## ネットワーク {#network}

Meno は、尋ねずにどこかへ接続することはありません。接続はその都度表示されます。質問には、その接続が何のためか、どこへつながるかが書かれています。許可は、Settings の「Network」で取り消すまで記憶されます。オフラインで作業するには、そこで「Work offline」をオンにするか、ウィンドウ右上のネットワークのボタンをクリックします。その間は何も外へ出ません。

## プラグイン {#plugins}

Meno の仕事の一部はプラグインが担います。SMILES と 3D 構造の化学、配座探索、構造最適化とエネルギー、計算プログラムの出力の読み取りなどです。プラグインは、初めて必要になったときに Meno が尋ねたうえで、必要なものを Meno 自身のフォルダにダウンロードして準備されます。Settings の「Plugins」に一覧があり、そこで追加や削除ができます。自分でインストールした計算プログラムはその場所のまま使われ、Meno がダウンロードすることはありません。

## Meno がファイルを置く場所 {#files}

- Mac：`~/Library/Application Support/Meno` に設定、プラグインとそれがダウンロードしたもの、計算ジョブがあります。`~/Library/Caches/Meno` には、Meno が保持する PDF の情報と、ダウンロードした配位子のデータがあります。
- Windows：`%APPDATA%\Meno` に設定があり、`%LOCALAPPDATA%\Meno\data` にそれ以外のものがあります。こちらは大きく、このコンピューターだけのものです。

自分のファイルは、保存した場所にあります。

## アンインストール {#uninstalling}

- Windows：「設定」→「アプリ」→「インストールされているアプリ」（Windows 10 では「アプリと機能」）→ Meno →「アンインストール」。アンインストーラーは、Meno のデータも削除するかを尋ねます。
- Mac：「アプリケーション」から Meno をゴミ箱にドラッグします。データも消すには、[上](#files)の二つのフォルダを削除します。
