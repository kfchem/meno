# PDF

論文の PDF をページに置き、作業の横で読み、その構造を編集できる構造として取り出し、ページから新しい PDF を作る方法です。

## PDF を開く {#opening}

- PDF を Meno のウィンドウにドロップします。ドロップしたところに、名前の付いたアイコンとして置かれます。いくつかまとめてドロップすることもできます。
- または、何もないところを右クリックして「Open…」を選びます（Mac では ⌘O、Windows では Ctrl+O）。
- PDF を右クリックして「Show full size」を選ぶと、ページが重なった形でページの上に見えます。「Minimize to an icon」でアイコンに戻ります。
- 同じメニューの「Delete PDF」か、PDF を指して Delete キーを押すと、ページから取り除けます。

## ページをめくる {#pages}

- 原寸で見せている PDF を指して ← と →（または Page Up と Page Down）を押すと、ページがめくれます。一番上のページを指していると角が折れます。右の角をクリックすると次のページ、左の角をクリックすると前のページです。
- 右クリックメニューにも「Previous page」と「Next page」があります。
- 「Spread pages」でページが横に並び、「Gather pages」で重なった形に戻ります。それぞれ別の場所へドラッグしたページは、「Put pages in rows」で列に戻ります。

## 読む {#reading}

PDF をダブルクリックするか、右クリックメニューで「Read」を選びます。ページの右に欄が開き、ページが上から順に並びます。欄の上には、読んでいる PDF やテキストごとにタブがあります。

- ホイールでスクロールします。ピンチするか、⌘（Windows では Ctrl）を押しながらホイールを回すと、拡大と縮小ができます。← と → で 1 ページずつ進みます。
- ページ番号をクリックすると、そのページへ移れます。ダブルクリックすると、ページが欄の幅に合います。
- 「Fill the workspace」（⇧⌘F、または Ctrl+Shift+F）で欄がウィンドウ全体に広がり、「Back beside the canvas」で元に戻ります。
- 「Hide texts」で欄が閉じます。PDF はページに残ります。何もないところの右クリックメニューにある「Show texts」で、また開きます。

## 言葉を探す {#find}

何もないところを右クリックして「Find in PDF…」を選びます（⌘F、または Ctrl+F）。欄の上に入力欄が開くので、探す言葉を打ち、「This PDF」か「All PDFs」を選びます。Enter で次に見つかったところへ、Shift+Enter で前へ移り、Escape で入力欄が閉じます。

## 構造を取り出す {#structures}

論文のように線と文字で描かれた構造は、プラグインなしで Meno が自分で読みます。

- 読む欄で構造を指すと光ります。ページへドラッグすると、そこに置かれ、自分で描いた構造と同じように編集できます。
- または、構造をクリックして選び（⌘ か Shift を押しながらクリックすると増やせます）、右クリックして「Put on the page」で PDF の横に置くか、「Copy」でコピーします。
- 欄で言葉を選んでページへドラッグすると、ページの文字になります。その文字の右クリックメニューの「Show in the PDF」で、元の場所へ戻れます。

図から読んだ構造は、指すとどこから来たかを示します。Meno が一部に自信を持てない間は、そばに "Read from a figure: check it" という注記が、自信のない部分の数とともに出ます。図と見比べ、正しければ、その原子か結合、または注記を右クリックして「Checked against the figure」を選びます。

## 画像としての図 {#figures}

- 読む欄で、図の上か言葉のないところをドラッグすると、四角で囲めます。図の中をクリックすると、図全体が囲まれます。ページの上に原寸で見せている PDF では、拡大してから長押ししてドラッグします。
- 四角をページへドラッグすると、その部分の画像になります。右クリックすると「Put on the page」「Copy picture」「Read as structure」が出ます。
- 「Read as structure」は、線で描かれた四角なら Meno が自分で読みます。スキャンや画像として保存された図は、画像から構造を読むプラグイン（MolScribe か MolNexTR）が読みます。初めてのときは、Meno がダウンロードしてよいか尋ねます（[インストール](installing#plugins)）。

## PDF に書き込む {#writing}

PDF の右クリックメニューで「Write on it」を選びます。ペンのカードが開き、「Pen」「Marker」「Eraser」が並びます。「Done」か Escape で終わります。書いたものは、そのページに残ります。

## ページから新しい PDF を作る {#making}

Meno は受け取った PDF を書き換えません。次のどれも新しい PDF を作り、元の PDF の横にアイコンとして置きます。

- 「Page numbers…」：すべてのページの下に番号を付けます。1, 2, 3 か S1, S2, S3 を、選んだ番号から、左・中央・右のどこかに付けます。「Make numbered copy」で作ります。
- 「Pages…」：ページが一列に並びます。ドラッグで順番を変えられます。ページを選び（クリック、Shift を押しながらクリック、⌘ か Ctrl を押しながらクリック、または「Select pages」に 1-3 のように番号を打ちます）、「Turn left」「Turn right」で回したり、「Take out」で外したりできます。「Make new PDF」で作ります。選んだページだけで作るときは、その横のボタンを使います。
- PDF を二つ以上選び、その一つを右クリックして「Combine into one PDF」を選びます。
- 「Save as PDF…」で、PDF を選んだ場所にファイルとして保存します。

## ワークスペースに保たれる {#kept}

ページにある PDF は、ワークスペースと一緒に .meno ファイルに保存されます。元の PDF をどこへ移しても、ワークスペースを開けば PDF も一緒に開きます。
