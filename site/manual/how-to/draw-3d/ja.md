# 構造を描いて 3D で見る

ポインターで環を描くと、その 3D 構造が描いた図から立ち上がります。

1. {#set-up} Meno を初めて起動すると、左下のカードが「Set up chemistry?」と尋ねます。「Set up」を選ぶと、化学のプラグインをオンラインのプラグイン一覧から取得して、一度だけ設定します。
2. {#open-quick-add} ページの何もないところをダブルクリックします。
3. {#chain} 「Chain」を選びます。
4. {#lead-ring} ボタンを押さずに、ポインターを環の六つの角に沿って動かし、始めたところでクリックします。
5. {#right-click} 環の原子を右クリックします。
6. {#make-3d} 「3D structure」を選びます。メニューの上にある「3D」です。3D 構造が構造式から立ち上がり、その横に収まります。
