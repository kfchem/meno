# 触媒サイクルを描く

触媒サイクルをページに置き、その線の上に触媒と二つの中間体を書いて、入ってくるものと出ていくものの矢印を付けます。

1. {#open-quick-add} ページの何もないところをダブルクリックします。アイコンの列が開きます。
2. {#scheme} プラスと曲がった矢印のアイコン「Scheme」を選びます。その下にもう一列開きます。
3. {#cycle} 矢印でできた円のアイコン「Catalytic cycle」を選びます。ダブルクリックしたところに円が置かれます。作業しているあいだ、円は選ばれたまま青く表示されます。
4. {#catalyst-open} 円の線のいちばん下をダブルクリックします。そこにアイコンの列が開きます。
5. {#catalyst-text} T のアイコン「Text」を選びます。
6. {#catalyst} `L2Pd(0)` と入力して Enter を押します。2 はひとりでに下付きになり、円の線は式をよけて描かれます。
7. {#second-open} 円の線の左上をダブルクリックします。
8. {#second-text} 「Text」を選びます。
9. {#second} `L2Pd(Ar)X` と入力して Enter を押します。最初の式からこの式へ、時計回りの矢印ができます。
10. {#third-open} 円の線の右上をダブルクリックします。
11. {#third-text} 「Text」を選びます。
12. {#third} `L2Pd(Ar)Ar'` と入力して Enter を押します。円は時計回りの三本の矢印になります。
13. {#arrow-in-menu} 一つ目と二つ目の式のあいだ、二つ目の式の少し下にある左側の線を右クリックします。
14. {#arrow-in} 「Arrow coming in」を選びます。外から曲がって入ってくる矢印が、そこで線に合流します。
15. {#arrow-in-words} そのまま `Ar-X` と入力して Enter を押します。式は矢印の外側の端に付きます。
16. {#metal-in-menu} 二つ目と三つ目の式のあいだ、いちばん上の線の真ん中より少し左を右クリックします。
17. {#metal-in} 「Arrow coming in」を選びます。
18. {#metal-in-words} そのまま `Ar'-M` と入力して Enter を押します。
19. {#metal-out-menu} 同じ線の、真ん中より少し右を右クリックします。
20. {#metal-out} 「Arrow going out」を選びます。この部分の線に、入ってくる矢印と出ていく矢印が一本ずつ付きます。
21. {#metal-out-words} そのまま `M-X` と入力して Enter を押します。
22. {#arrow-out-menu} 三つ目と一つ目の式のあいだ、三つ目の式よりかなり下、円のいちばん右の線を右クリックします。
23. {#arrow-out} 「Arrow going out」を選びます。そこから線を離れて外へ曲がっていく矢印ができます。
24. {#arrow-out-words} そのまま `Ar-Ar'` と入力して Enter を押します。
25. {#let-go} ページの何もないところをクリックします。サイクルの選択が外れ、描かれたとおりの姿が見えます。入るものと出るものの矢印がそれぞれの段階に付き、すべて時計回りに進みます。
